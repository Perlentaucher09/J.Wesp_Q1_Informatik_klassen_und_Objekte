# J.Wesp_Q1_Informatik_klassen_und_Objekte

Uebungsprojekt fuer Q1 Informatik zum Thema Klassen und Objekte in Java.

## Inhalt

Das Projekt enthaelt ein einfaches Beispiel zur Modellierung eines Pakets mit:

- Konstruktor
- privaten Attributen
- Methoden zum Anzeigen und Aendern des Status

## Dateiuebersicht

- Main.java: Einstiegspunkt mit Testdaten und Programmausgabe

## Ausfuehren

Im Projektordner:

```bash
javac Main.java
java Main
```
